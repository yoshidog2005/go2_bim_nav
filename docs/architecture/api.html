    2Sensing

    How does robot data reach ROS?

    The Go2 publishes on CycloneDDS domain 0. This stack runs on ROS domain 1 with Fast DDS, so data is bridged across.

    6Navigation

    How do I get there without hitting anything?

    No code from this repo here: it's Nav2, configured in nav2_params.yaml. Nodes are started by nav2_bringup.

    Nav2 nodes in this use case

    NodeRoleConfigured
    bt_navigatorServes navigate_to_pose and runs the behaviour tree: plan → smooth → follow, recover on failure.global_frame map, robot_base_frame base_link, odom_topic /utlidar/robot_odom, Humble default trees
    planner_serverGlobal route on the global costmap.GridBased = NavfnPlanner, use_astar true, tolerance 0.5, allow_unknown false
    smoother_serverRounds off the route.simple_smoother = SimpleSmoother, max_its 1000
    controller_serverFollows the path and dodges obstacles on the local costmap; outputs cmd_vel_nav.20 Hz, FollowPath = DWBLocalPlanner, max_vel_x 0.8, max_vel_theta 1.0, acc_lim_x 1.0, sim_time 1.5; goal_checker 0.20 m / 0.15 rad; progress_checker 0.5 m in 10 s
    behavior_serverRecoveries when stuck; outputs cmd_vel_nav.spin, backup, wait; max_rotational_vel 1.0
    velocity_smootherLimits speed and acceleration; cmd_vel_nav → /cmd_vel.20 Hz, OPEN_LOOP, max [0.8, 0, 1.0], min [−0.4, 0, −1.0], accel [1.0, 0, 2.0]
    waypoint_followerStarted by bringup; not used by this repo's scripts.wait_at_waypoint 200 ms

    8Robot test tools

    Is the robot and network working, without Nav2?

    Stand-alone scripts in examples/. The obstacles_avoid ones drive the Go2 with its firmware navigation and avoidance through the Unitree SDK, bypassing this repo's Nav2 stack entirely. Run them with the dog standing, clear space around it, and the remote in hand.

    test_nav2point.py

    script · Unitree SDK
    python3 examples/obstacles_avoid/test_nav2point.py ethrobot

    Prompts for x y yaw, measured from where the dog started up, and sends it to the firmware's own point navigation. Waits a fixed 15 s per goal (it doesn't check arrival). Stops the dog and releases API control on exit.
