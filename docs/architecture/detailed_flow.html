Go2 LiDAR

robot

Built-in head LiDAR (utlidar)

  • publishes rt/utlidar/cloud_base
  • type PointCloud2_ (unitree IDL)
  • CycloneDDS, domain 0, iface ethrobot

ifc_to_map.py

workstation

BIM model → floor map

  • main(--input, --output, --resolution 0.05, --padding 1.0, --storey, --include-types, --no-clear-doors, --door-padding 0.05)
  • project_triangles(model, include_types, storey_name) → yields [(x, y)×3]
  • door_bounding_boxes(model, storey_name, padding) → (min_x, min_y, max_x, max_y)
  • rasterise(triangles, resolution, padding, clear_boxes) → (img, origin)
  • write_map(img, origin, resolution, output_prefix) → .pgm, .yaml
  • check with preview_map.py main(--map, --save)

Go2 odometry

robot

The robot's own motion estimate

  • topic /utlidar/robot_odom
  • nav_msgs/Odometry, frame odom → child base_link
  • also read directly by bt_navigator, controller_server, velocity_smoother (odom_topic)

⚠ Nothing in the repo puts this on ROS domain 1. WALKTHROUGH's lidar_restamp.py may have, but it's missing.

lidar_bridge.py

by hand

Robot network → ROS

  • main(): rclpy.init(args=sys.argv); Node("go2_lidar_bridge")
  • create_publisher(PointCloud2, "/utlidar/cloud", SENSOR_DATA)
  • ChannelFactoryInitialize(0, "ethrobot")
  • ChannelSubscriber("rt/utlidar/cloud_base", PointCloud2_).Init(on_cloud, 10)
  • on_cloud(msg) → to_ros_cloud(msg, PointCloud2, PointField, clock) → pub.publish(out)

pointcloud_to_laserscan

launched

3D cloud → flat 2D scan

  • remap cloud_in ← lidar_cloud_topic, scan → /scan
  • target_frame base_link
  • min_height 0.05, max_height 0.35 m
  • angle −π…π, step 0.0087; range 0.15–12.0 m

odom_to_tf.py

launched

Odometry topic → tf

  • class OdomToTf(Node)
  • __init__(): TransformBroadcaster(self); create_subscription(Odometry, '/utlidar/robot_odom', _on_odom, qos_profile_sensor_data)
  • _on_odom(msg) → TransformStamped(stamp=now(), odom → base_link, msg.pose) → sendTransform(t)
  • only if use_odom_to_tf:=true

local_costmap

nav2_bringup

What's right around the robot

  • frame odom, rolling 6×6 m @ 0.05 m, 10 Hz
  • ObstacleLayer(/scan) → InflationLayer(radius 0.4, scale 3.0)
  • footprint 0.70 × 0.32 m (placeholder)
  • also read by behavior_server

amcl

nav2_bringup

Where am I on the BIM map?

  • likelihood_field, DifferentialMotionModel
  • 500–2000 particles, 60 beams
  • set_initial_pose (0, 0, 0) or RViz /initialpose
  • → publishes tf map → odom

map_server

nav2_bringup

Serves the BIM map

  • yaml_filename ← launch arg map
  • → /map nav_msgs/OccupancyGrid

global_costmap

nav2_bringup

Whole floor: BIM + live obstacles

  • frame map, 1 Hz, track_unknown_space
  • StaticLayer(/map) → ObstacleLayer(/scan) → InflationLayer(radius 0.4)

send_goal.py

by hand

“Go here”

  • main(--x, --y, --yaw 0.0, --frame-id map, --waypoint, --waypoints-file)
  • load_waypoint(waypoints_file, name) → (x, y, yaw)
  • class GoalSender(Node): ActionClient(self, NavigateToPose, 'navigate_to_pose')
  • send(x, y, yaw, frame_id): wait_for_server(10 s) → yaw_to_quaternion(yaw) → send_goal_async(goal, feedback_callback=_feedback_cb) → get_result_async()
  • exit 0 if STATUS_SUCCEEDED, else 1

bt_navigator

nav2_bringup

Runs the navigation behaviour tree

  • action server navigate_to_pose
  • Humble default tree: plan → smooth → follow, recover on failure
  • global_frame map, robot_base_frame base_link

planner_server

nav2_bringup

Global route

  • GridBased = NavfnPlanner
  • use_astar true, tolerance 0.5, allow_unknown false
  • ComputePathToPose → nav_msgs/Path

smoother_server

nav2_bringup

Rounds off the route

  • SimpleSmoother, max_its 1000
  • SmoothPath(Path) → Path

controller_server

nav2_bringup

Follows the route, dodges obstacles

  • 20 Hz; FollowPath = DWBLocalPlanner
  • max_vel_x 0.8, max_vel_theta 1.0, sim_time 1.5
  • critics: RotateToGoal, Oscillation, BaseObstacle, GoalAlign, PathAlign, PathDist, GoalDist
  • goal_checker xy 0.20 m, yaw 0.15 rad; progress 0.5 m / 10 s

velocity_smoother

nav2_bringup

Limits speed and acceleration

  • 20 Hz, OPEN_LOOP
  • max_velocity [0.8, 0, 1.0], min [−0.4, 0, −1.0]
  • max_accel [1.0, 0, 2.0]
  • cmd_vel_nav → /cmd_vel

behavior_server

nav2_bringup

Recoveries when stuck

  • Spin, BackUp, Wait
  • reads local_costmap/costmap_raw
  • max_rotational_vel 1.0

cmd_vel_bridge.py

launched

Twist → Go2 Sport API

  • class CmdVelBridge(Node)
  • __init__(): create_publisher(Request, '/api/sport/request', 10); create_subscription(Twist, '/cmd_vel', _on_cmd_vel, 10); create_timer(0.1, _check_watchdog)
  • _on_cmd_vel(msg) → _publish_move(linear.x, linear.y, angular.z)
  • _publish_move(vx, vy, vyaw) → Request(api_id 1008, parameter {"x","y","z"})
  • _check_watchdog(): no /cmd_vel for 0.5 s → _publish_stop() (api_id 1003)
  • main() finally → _publish_stop()
